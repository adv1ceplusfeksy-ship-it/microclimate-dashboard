# Дашборд закрытой агросистемы

Актуальные файлы:
- dashboard.html — основная вкладочная версия web-приложения.
- dashboard_tabs_v9.html — копия актуальной версии.
- data/microclimate_emulated_14d.csv — полный набор телеметрии.
- data/microclimate_wide_for_dashboard.csv — данные в широком формате для графиков.
- results/dli_daily.csv — DLI и climate compliance по дням.
- results/metrics_summary.csv — метрики валидации.

Вкладки приложения:
1. Обзор
2. Временные ряды
3. Агропоказатели
4. События
5. Архитектура
6. Качество данных
7. Валидация
